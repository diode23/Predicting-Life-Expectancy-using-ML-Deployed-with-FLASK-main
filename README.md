## 🚀 Descripción del proyecto

Esta aplicación web utiliza **Machine Learning** para predecir la **esperanza de vida** de una persona a partir de factores como ingresos, educación y acceso a la atención médica.

El modelo está basado en **Regresión Lineal** y fue entrenado con datos provenientes de la **Organización Mundial de la Salud (OMS)**, disponibles en Kaggle.

La aplicación está desarrollada con **Flask**, lo que permite al usuario ingresar valores desde una interfaz web y recibir una predicción de forma rápida e intuitiva.

## ✨ Características

- 🤖 Modelo de regresión lineal entrenado con datos de la OMS.
- 🌐 Aplicación web desarrollada con Flask.
- 📊 Predicción de esperanza de vida basada en variables socioeconómicas y sanitarias.
- 🧠 Uso de scikit-learn para el entrenamiento del modelo.
- 🖥️ Interfaz sencilla y fácil de usar.
- 📈 Ideal para aprender sobre Machine Learning, Flask y despliegue de modelos.

## 📦 Instalación

Clona este repositorio en tu computadora:

```bash
git clone [https://github.com/tu-usuario/tu-repositorio.git](https://github.com/tu-usuario/tu-repositorio.git)
cd tu-repositorio
```

Instala las dependencias necesarias:

```bash
pip install -r requirements.txt
```

Esto instalará las librerías necesarias, incluyendo:

- Flask
- scikit-learn
- Pandas
- NumPy

## ▶️ Uso

Para ejecutar la aplicación, navega al directorio del proyecto y ejecuta el siguiente comando:

```bash
python app.py
```

Luego, abre tu navegador y accede a:

```text
http://localhost:5000/
```

## 🧪 Cómo utilizar la aplicación

1. Ingresa los valores de los factores que influyen en la esperanza de vida.
2. Haz clic en el botón **“Predecir”**.
3. El modelo procesará los datos y mostrará la esperanza de vida estimada.

### 📌 Ejemplo

Si un usuario ingresa los siguientes valores:

- 💰 Ingresos: $50,000
- 🎓 Educación: 12 años
- 🏥 Atención médica: 5.0

El modelo puede generar una predicción como:

```text
Esperanza de vida predicha: 78.5 años
```

El resultado depende de los valores ingresados y de la precisión del modelo de Machine Learning.
